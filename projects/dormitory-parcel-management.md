# Dormitory Parcel Management System
**Project case study · Danaiphong Songsikhwa · QA / Tester**

[Back to my profile](https://github.com/danai2004)

## The problem
Dormitory staff need to record incoming parcels, find them quickly and track collection. The earlier Google Forms and Sheets workflow made searching and handling several parcels for one room difficult.

## The team solution
The team built a web application with batch parcel intake, duplicate tracking-number checks, room-based search, collection of several parcels at once, a dashboard and history.

## My contribution
- Supported testing of parcel intake, search and collection workflows.
- Helped check error cases and possible security issues.
- Helped prepare bug reports and suggested fixes for the development team.
- Contributed frontend improvements and layouts for different screen sizes.

My role was part of a team effort. This page does not claim that I built the whole system or independently found every issue.
